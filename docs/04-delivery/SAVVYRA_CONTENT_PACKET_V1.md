# Savvyra

**Personal Finance Management, Designed Around Everyday Life**

**Category:** Development
**Project Type:** Solo Personal Project
**Role:** Full-Stack Developer & UI/UX Designer

## Project Summary

A full-stack personal finance web application that brings salary planning, transactions, savings, commitments, debts, and investments into one connected experience.

## Overview

Savvyra is a personal finance management web application I designed and developed to make everyday financial activities easier to organize and understand.

It combines financial tracking, salary planning, savings goals, recurring commitments, debt management, and investment records with interactive dashboards that present financial information in a more accessible way.

## The Challenge

Managing personal finances involves more than recording income and expenses.

Understanding monthly commitments, planning salary allocations, monitoring debts, and tracking savings goals can become difficult when financial information is spread across separate records.

I wanted to explore how these responsibilities could be brought together in a single, approachable interface.

## My Role & Contributions

As the solo Full-Stack Developer and UI/UX Designer, I was responsible for the project's design direction, application structure, frontend development, backend integration, and iterative refinement.

I incorporated AI-assisted development into my workflow while remaining responsible for reviewing suggestions, making design and technical decisions, integrating functionality, testing, and debugging.

## Design & Development Approach

### 01. Organizing Financial Information

I structured the application around distinct financial activities while maintaining a central dashboard for an overview of income, expenses, savings, debts, commitments, and investments.

### 02. Creating a Cohesive Interface

I developed a purple-themed visual identity using gradients, glass-style surfaces, interactive charts, and reusable UI components.

The interface was designed with responsive layouts to accommodate different screen sizes.

### 03. Connecting Frontend and Backend

I implemented Next.js API functionality and used Prisma ORM with PostgreSQL hosted on Supabase to manage application data.

The database schema connects user accounts with financial records across the application's different modules.

### 04. Implementing Financial Logic

I worked on functionality for salary calculations, recurring commitments, savings progress, debt records, and dashboard summaries.

The codebase also includes transaction-linked logic that updates certain debt and commitment payment states.

### 05. Iterating and Refining

Throughout development, I refined components, forms, application states, and user interactions through testing and debugging.

## Key Features

- Interactive financial dashboard and data visualization
- Income and expense transaction management
- Savings accounts and savings goals
- Salary calculation and monthly financial planning
- Recurring commitments and payment tracking
- Debt and repayment management
- Investment records and summaries
- Authentication and account management

## Technology Stack

**Frontend:** Next.js, React, TypeScript, Tailwind CSS
**Backend:** Next.js API Routes
**Database:** PostgreSQL (Supabase), Prisma ORM
**Visualization:** Recharts
**UI & Motion:** Framer Motion, Lucide React

## Outcome & Reflection

Savvyra became a practical exploration of full-stack product development, combining financial data modeling, application logic, and interface design within one project.

It allowed me to work through interconnected features, organize reusable components, and refine how backend data is presented through interactive interfaces.

The project reflects my interest in building useful digital products that balance technical functionality with approachable user experiences.

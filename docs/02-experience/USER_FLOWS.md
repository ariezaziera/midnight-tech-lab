# User Flows

## Recruiter
Home/About → Projects → Case Study → About/CV → Contact. No 3D prerequisite.

## Freelance client
Home/Services → Service Detail → Related Work → Contact. Never imply booking/payment without implementation.

## Explorer
Home → Hover/select Development Lab → Camera Focus → Click project display → Preview → Case Study → Return to studio.

## Keyboard/reduced-motion visitor
Skip intro → global navigation → direct pages → accessible buttons and dialogs. Camera moves instantly or minimally when reduced motion is enabled.

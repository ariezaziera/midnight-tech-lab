# Interaction Specification

## Input conventions
- Desktop hover: optional preview/highlight only; click activates.
- Touch: tap activates; no hover-dependent critical information.
- Keyboard: focusable HTML equivalent for every meaningful hotspot; Enter/Space activates.
- Escape closes dialogs; Back returns to prior page/preset when safe.

## Hotspot mapping
1. Creator ID → About panel/route.
2. Main Workstation → featured/current projects.
3. Navigation Console → module selector.
4. Featured Project Display → project preview → case study.
5. Holographic Globe → module map (later milestone).
6. Cozy Corner → optional personal content (later milestone).

## Overlay requirements
Use accessible dialog behavior with title, close button, focus trap and focus restoration. Pause distracting camera movement behind reading overlays. Do not open multiple overlapping dialogs.

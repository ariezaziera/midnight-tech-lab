# Content Guidelines

Verified candidate project names from user context: Savvyra, Optima Bank Loyalty Web App, Markerless AR Melaka. Confirm public naming, permission, roles, images and links before publishing. Do not publish confidential employer information.

Project data fields: `slug`, `title`, `summary`, `categories`, `role`, `problem`, `contribution`, `process`, `solution`, `outcomes`, `technologies`, `images`, `demoUrl?`, `repoUrl?`, `featured`.

Never invent statistics, completion dates, testimonials, client names, contact information, or a portrait. Mark incomplete content `DRAFT` and exclude it from production public routes if misleading.

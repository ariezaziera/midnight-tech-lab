# Style Guide

## Visual principles
1. Cosmic but professional: atmospheric 3D behind legible UI.
2. Cozy realism: amber practical lights, textured desk props, personal touches.
3. Intentional interaction: only primary/secondary objects clickable.
4. Portrait integration: actual user-supplied portrait in Creator ID and conventional About/hero UI.
5. Avoid dense neon text and excessive bloom; preserve contrast and hierarchy.

## Copy principles
Human, credible, first-person solo-creator voice. Do not imply an agency team or invent results. Write concise descriptions, explicit service scope and direct calls to action.

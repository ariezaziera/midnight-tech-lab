# Responsive Design

- Desktop: cinematic interactive scene with standard global nav and readable overlay panels.
- Tablet: simplified camera controls and fewer decorative effects.
- Mobile: prioritize content-first editorial UI, reduced scene complexity, large tap targets and direct navigation; optional simplified 3D scene.
- Use responsive CSS layouts; avoid shrinking desktop design to mobile scale.
- Support landscape and portrait, browser zoom, long text and reduced motion.
- Validate at 320px, 390px, 768px, 1024px and 1440px widths; these are test widths, not rigid design breakpoints.

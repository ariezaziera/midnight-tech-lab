# Screen Specifications — v1

All dimensions are provisional until screenshot-based visual QA. Each screen must have keyboard-accessible, responsive HTML content.

## HOME-001 — Central Hub
- Full viewport cinematic scene, persistent global nav, visible creator identity and primary CTA.
- Six conceptual hotspots: Creator ID, Main Workstation, Navigation Console, Featured Project Display, Holographic Globe, Cozy Corner.
- Overview/reset/back controls, reduced motion, skip intro, loading and fallback.
- Desktop: scene foreground with non-obscuring nav/overlay; mobile: simplified visual + direct actions.

## PROJECTS-001 — Project Library
- Heading and short description; filters (All, Development, UI/UX, Interactive Media, Graphic Design) as applicable to actual content.
- Responsive project card grid: image, title, brief descriptor, categories, project detail action.
- Filters reflected in accessible UI state; empty state if no matches.

## CASE-001 — Case Study
- Back to Projects, project title, verified role and summary, hero media, tags, demo/code links only if valid.
- Sections: Overview, Problem, Contribution, Process, Solution, Outcomes, Reflection, Next Project (omit or label unverified sections).
- No fabricated metrics, client names, testimonials or dates.

## ABOUT-001 — About
- Real portrait when supplied; intro, authentic education/experience, skills and CV download only if file exists.
- Optional personal corner/candid photos require approval.

## SERVICES-001 — Services
- Solo creator framing, service cards for web/apps, UI/UX, interactive media and graphic design **only if confirmed offered**.
- Each service: deliverables, scope, sample related work, process and inquiry CTA.

## CONTACT-001 — Contact
- Clear contact methods, accessible form UI only if backed by functional secure delivery.
- If backend not yet built: use verified mailto/contact link and do not render fake-success submission.

## Shared behavior
- Global navigation across all routes; current route indicator; return to 3D studio action.
- Overlay: accessible dialog semantics, close via button/Escape, focus restoration, no scroll bleed.
- Desktop baseline review 1440x900; mobile baseline 390x844; additional tablet and narrow-mobile checks.

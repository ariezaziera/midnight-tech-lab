# Project Overview

**Name:** Midnight Tech Lab  
**Owner:** Arieza  
**Project type:** New standalone personal portfolio and solo creative-studio storefront.  
**Creative positioning:** Creative Technologist combining development, design, and interactive media.

## Vision
A premium, cinematic, midnight-cosmic digital studio where floating workstation islands showcase work, services and personality. The 3D experience is a memorable showroom; ordinary accessible pages remain the source for detailed content.

## Audiences
- Recruiters: identity → projects → experience/CV → contact.
- Freelance clients: services → relevant work → process → inquiry.
- Curious visitors: 3D exploration → object preview → case studies.

## Core promise
Visual distinctiveness without sacrificing clarity, accessibility, performance or credibility.

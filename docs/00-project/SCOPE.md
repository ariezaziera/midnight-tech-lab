# Scope and Boundaries

## MVP release boundary
Deliver a coherent functional portfolio plus a single Central Hub 3D vertical slice. Use blockout geometry until high-quality models are supplied or approved.

## Subsequent modules
Development Lab, Design Studio, Media Lab, Services Terminal and Personal Corner. Personal Corner's separate-island vs embedded-hub location is **unresolved**.

## Change control
For any new feature: record user goal, impact on performance/accessibility, dependencies, acceptance tests and whether it replaces an existing milestone.
